# Agent Guidelines & Repository Configuration

This repository follows strict **Caveman** and **Ponytail** principles for agent interactions and code contributions.

## Active Rules
- [Caveman Rule](file:///.agents/rules/caveman.md): Token optimization, direct communication, zero fluff.
- [Ponytail Rule](file:///.agents/rules/ponytail.md): Pragmatic, lean, YAGNI-driven, and high-performance code design.
